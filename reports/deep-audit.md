# Deep Engineering Audit

The audit covered backend domains, connectors, API contracts, SQLite/FTS, exports, scripts,
frontend state, localization/RTL, shadcn overlays, tests, Docker, and documentation. Findings below
are evidence-based; severity describes user-visible operational impact, not code style.

## Residual Risks

- Near-duplicate comparison is quadratic in the bounded interactive candidate set. The final
  benchmark measured 342.89 ms at 200 records; collection is capped at 200.
- Broad ambiguous terms remain a lexical limitation. A local semantic reranker was not enabled
  because no measured improvement/cost evidence was established.
- Source Confidence, Cross-Source Presence, and Novelty are constant in the hard ranking fixture;
  stored-session diagnostics, not that fixture alone, must be used for operational calibration.
- Platform access, quota, and geographic/CDN behavior remain external dependencies.
